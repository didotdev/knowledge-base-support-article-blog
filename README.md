# DevBase Blog

A lightweight static developer knowledge-base blog.

## Pages
- `index.html` — homepage
- `article.html` — article detail example
- `category.html` — topic/category listing page
- `support.html` — support/contact page

## Run locally
Open the directory in a browser or serve it with a local static server.

Example:

```bash
python -m http.server 8000
```
